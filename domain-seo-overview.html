What it does

Domain SEO Overview (hirepulse/domain-seo-overview)

A domain-level SEO reconnaissance Actor that builds an evidence-based overview of a website by extracting page metadata, discovering and inspecting sitemaps and listed URLs, harvesting Google Autocomplete keyword suggestions with provenance and availability indicators, and reporting site popularity buckets derived from the Chrome UX Report origin rankings; outputs are structured JSON records containing page titles and meta descriptions, sitemap URL observations and counts, suggested keywords with source context, and site popularity metrics and traffic-related estimates where available. This Actor is designed for automated domain inspection, competitor site comparisons, and metadata-driven keyword discovery workflows.

Use cases

  • Inspect a site before a technical SEO audit
  • Competitor website research and comparison
  • Brand monitoring and site-wide metadata review
  • Sitemap discovery and URL inventory for crawling or index checks
  • Generating keyword suggestion lists using Google Autocomplete signals
