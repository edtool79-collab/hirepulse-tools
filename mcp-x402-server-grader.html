What it does

MCP & x402 Evidence Grader

A non-destructive inspection tool that probes public MCP endpoints' tool catalogs and x402 endpoints' unpaid payment challenges to extract technical evidence, run per-tool documentation checks, and generate review drafts and a local documentation grade. The Actor analyzes HTTP responses and endpoint structure to record observed tool counts, per-tool compliance and behavior checks, structural findings for x402 challenges, and draft review text for server owners; it preserves declared schemas and does not modify remote servers or execute payment transactions. Outputs are consolidated diagnostic reports and heuristic grades intended for owner review and documentation remediation.

Use cases

  • Inspect an MCP endpoint's tool catalog to enumerate tools and perform per-tool documentation and behavior checks.
  • Examine an x402 unpaid payment challenge to extract structural findings and HTTP-status evidence.
  • Export observed technical evidence and documentation checks for review and remediation.
  • Produce optional draft review text for server owners summarizing findings and suggested follow-up.
  • Generate heuristic, local documentation grades to prioritize remediation and verification efforts.
