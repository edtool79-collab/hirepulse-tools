What it does

Keyword Research: Google Autocomplete & Suggestions

Expands seed phrases into Google Autocomplete and suggestion results to generate long-tail keyword ideas and structured keyword datasets for SEO and content planning. The Actor queries public and platform-native autocomplete sources to produce structured JSON records containing suggested keyword phrases, optional numeric metrics when provided via configured paid upstream providers, explicit indicators that signal whether measured metrics are available versus numeric zero, and source attribution for each suggestion. Core mechanisms include bulk processing of keyword lists, expansion of seed terms into public autocomplete suggestions, and optional integration with paid data sources for measured metrics.

Use cases

  • Expanding seed keyword lists into autocomplete-based suggestion inventories
  • Processing keyword lists and exporting structured records for analysis
