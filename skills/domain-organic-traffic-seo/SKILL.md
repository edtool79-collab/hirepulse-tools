# Domain SEO public-evidence preview

Use this tool to inspect public website titles, meta descriptions, sitemap observations and autocomplete suggestions. Do not use its native mode to estimate traffic, measure ranking positions, search volume or CPC. Unavailable SEO metrics remain null; autocomplete order is not search rank.

Actor: https://apify.com/hirepulse/domain-seo-overview

MCP: https://mcp.apify.com?tools=hirepulse/domain-seo-overview

Input:

```json
{"domains":["example.com"],"country":"US","top_keywords":0,"competitors":0,"use_paid_upstream":false}
```

Native mode emits no custom lookup/result charges, but the Actor start fee and applicable Apify charges still apply. Read the live Pricing tab and set a spending cap. Do not enable paid upstream or submit payment credentials as part of this preview.

Details and a dated real owner-run sample: https://edtool79-collab.github.io/hirepulse-tools/domain-seo-overview-api.md
