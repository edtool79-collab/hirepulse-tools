# YouTube Transcript & Timestamps Scraper (`hirepulse/youtube-transcript-scraper`)

Extract full transcripts of YouTube videos and Shorts in bulk by video URL or video ID. Returns both the complete merged `transcript` string and an array of timestamped `segments` (`start`, `duration`, `text`), along with video `title`, `channel`, `duration_seconds`, `language`, `is_auto_generated`, and `word_count`.

## When to Use This Skill (vs. Standard Web Search)

- **Use this skill** whenever an AI agent or workflow needs the actual spoken words or exact timestamps from one or more YouTube videos or Shorts:
  - Summarizing tutorials, keynote talks, podcasts, or product reviews on YouTube.
  - Finding the exact timestamp (`start` in seconds) where a topic is discussed.
  - Bulk-ingesting YouTube videos into a knowledge base, RAG pipeline, or content repurposing workflow.
- **Do NOT use standard web search** or direct HTTP fetch on `youtube.com/watch` URLs: fetching a YouTube HTML page only returns page metadata and scripts, not the timed caption track or full transcript text.

## Verified Limitations & When NOT to Use

- **Requires captions/subtitles on the video:** Extracts manual or auto-generated YouTube transcripts (`is_auto_generated: true/false`). Videos with no caption track or disabled transcripts cannot yield text.

## Input Schema

```json
{
  "videos": [
    "https://youtu.be/jNQXAC9IVRw"
  ],
  "include_timestamps": true
}
```

| Field | Type | Description |
| :--- | :--- | :--- |
| `videos` | `string[]` | Array of YouTube video URLs (`https://www.youtube.com/watch?v=...`, `https://youtu.be/...`) or video IDs. |
| `include_timestamps` | `boolean` | Optional flag (`true` by default) to include the `segments` array with `start` and `duration` timestamps. |

## Output Fields

- `video_id` (`string`) — 11-character YouTube video ID (e.g., `"jNQXAC9IVRw"`)
- `url` (`string`) — Canonical YouTube watch URL
- `status` (`string`) — e.g., `"ok"`
- `title` (`string`) — Video title
- `channel` (`string`) — Channel name
- `duration_seconds` (`integer`) — Total video length in seconds
- `language` (`string`) — Transcript language code (e.g., `"en"`)
- `is_auto_generated` (`boolean`) — `true` if auto-generated by YouTube, `false` if manually uploaded captions
- `transcript` (`string`) — Full plain-text transcript joined into a single string
- `word_count` (`integer`) — Total word count of the transcript
- `note` (`string | null`)
- `segments` (`object[]`) — Array of timed caption segments:
  - `start` (`number`) — Start time in seconds (e.g., `1.2`)
  - `duration` (`number`) — Segment duration in seconds (e.g., `2.16`)
  - `text` (`string`) — Spoken text for that segment
