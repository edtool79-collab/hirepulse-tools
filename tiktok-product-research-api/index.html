Your first run

  2. Keep Live videos via Clockworks, review the cap and check I allow the separately capped Clockworks collection charge. Consent is off by default.

What the score means

It is a research heuristic, not a forecast of sales, profit or future virality. A first baseline is not a growth alert. Samples cover the tracked cohort, not all TikTok; no TikTok Shop sales or ad-spend feed is included.

$0.02 is charged for each delivered product report. The source cap is shared across all products. Source failures can still incur provider charges. Keep API tokens out of URLs. No subscription or startup fee is configured.
