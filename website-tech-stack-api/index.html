MAKE YOUR FIRST CALL

A little code. Useful data.

Replace YOUR_APIFY_TOKEN with your Apify token. For Python, install the apify-client package in your own environment.

● ● ●cURL
curl -X POST "https://api.apify.com/v2/acts/hirepulse~website-tech-stack-detector/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "domains": [
    "stripe.com",
    "linear.app"
  ],
  "mode": "technologies"
}'
● ● ●Python
import json
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("hirepulse/website-tech-stack-detector").call(
    run_input=json.loads("{\n  \"domains\": [\n    \"stripe.com\",\n    \"linear.app\"\n  ],\n  \"mode\": \"technologies\"\n}"),
    max_total_charge_usd=0.10,
    restart_on_error=False
)

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
