# Keyword Research: Google Autocomplete & Suggestions

Generate Google autocomplete suggestions and keyword research ideas by seed, country and language.

## Coverage and limits

Native mode does not measure monthly search volume, CPC or difficulty; unavailable measurements remain null.

The Actor page documents the current fields and source limitations. `null` means unavailable, not zero. A schema field retained for compatibility is not proof that the current source mode measures that field.
