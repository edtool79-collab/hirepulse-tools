# Company Intent Radar: Hiring, Ads & Website Signals

Combine observed hiring, public ad, website and DNS evidence with an explainable intent estimate.

## Coverage and limits

A score is a heuristic, not proof of buying intent, growth or ad spend. Public mode does not measure SEO traffic.

The Actor page documents the current fields and source limitations. `null` means unavailable, not zero. A schema field retained for compatibility is not proof that the current source mode measures that field.
