MAKE YOUR FIRST CALL

A little code. Useful data.

Replace YOUR_APIFY_TOKEN with your Apify token. For Python, install the apify-client package in your own environment.

● ● ●cURL
curl -X POST "https://api.apify.com/v2/acts/hirepulse~aliexpress-search-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "queries": [
    "wireless earbuds"
  ],
  "max_results_per_query": 120,
  "ship_to": "US",
  "currency": "USD"
}'
● ● ●Python
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("hirepulse/aliexpress-search-scraper").call(
    run_input={
      "queries": [
        "wireless earbuds"
      ],
      "max_results_per_query": 120,
      "ship_to": "US",
      "currency": "USD"
    }
)

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
