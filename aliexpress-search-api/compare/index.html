Read changes as search observations.

A listing missing from the later export may have moved outside the search window; it does not prove stock loss. Price changes can reflect variants and promotions. This tool does not calculate delivery costs, profit, exact sales between dates or a complete catalog history. It cannot verify that the two runs used the same sort or result limit; keep those settings identical yourself.

Comparison files are processed locally. This page uses the site's page-visit analytics; product rows and file contents are not sent to analytics. The saved example is historical data, not live AliExpress prices.
