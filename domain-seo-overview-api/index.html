MAKE YOUR FIRST CALL

A little code. Useful data.

Replace YOUR_APIFY_TOKEN with your Apify token. For Python, install the apify-client package in your own environment.

● ● ●cURL
curl -X POST "https://api.apify.com/v2/acts/hirepulse~domain-seo-overview/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "domains": [
    "example.com"
  ],
  "country": "US",
  "top_keywords": 0,
  "competitors": 0,
  "use_paid_upstream": false
}'
● ● ●Python
import json
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("hirepulse/domain-seo-overview").call(
    run_input=json.loads("{\n  \"domains\": [\n    \"example.com\"\n  ],\n  \"country\": \"US\",\n  \"top_keywords\": 0,\n  \"competitors\": 0,\n  \"use_paid_upstream\": false\n}"),
    max_total_charge_usd=0.10,
    restart_on_error=False
)

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

BEFORE YOU BUILD

Frequently asked questions

What is included in the native preview?+

Public page titles, meta descriptions, sitemap observations and autocomplete suggestions. Availability depends on the target website.

Does this mode measure organic traffic or search rankings?+

No. Those metrics require a separately configured SEO data source. Null means unavailable, not zero. Autocomplete order is not a search ranking.

Is the native preview free to run?+

It emits no custom lookup/result charges, but the Actor start fee and applicable Apify charges still apply. Review the live Pricing tab.

Why do example tables include traffic fields?+

They are shared column definitions, not measured results for this mode. Read provider_mode, metrics_available, data_source and note in the returned JSON.

Where does this tool run?+

All hirepulse tools run on the Apify Store.

Do I need a subscription?+

No subscription is required. The tools are pay per use.

How do AI agents connect?+

Agents connect through Apify’s MCP server.
