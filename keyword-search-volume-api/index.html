MAKE YOUR FIRST CALL

A little code. Useful data.

Replace YOUR_APIFY_TOKEN with your Apify token. For Python, install the apify-client package in your own environment.

● ● ●cURL
curl -X POST "https://api.apify.com/v2/acts/hirepulse~keyword-search-volume/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "keywords": [
    "running shoes",
    "trail running shoes"
  ],
  "country": "US"
}'
● ● ●Python
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("hirepulse/keyword-search-volume").call(
    run_input={
      "keywords": [
        "running shoes",
        "trail running shoes"
      ],
      "country": "US"
    }
)

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
