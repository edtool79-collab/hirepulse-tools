What it does

Temporary Email Inbox & OTP API for AI Agents

Creates time-limited, private disposable inbound email inboxes and extracts numeric one-time passwords (OTPs) and their provenance from received SMTP messages. The Actor provisions a random private email address and associated secret access credential for the creating account, receives real inbound email, parses plain-text and HTML message content for 4–8 digit verification codes located near verification or OTP labels (including supported non‑Latin labels), and returns extracted numeric candidates with provenance metadata such as a message identifier, receipt/expiry timestamps, extraction method, source indicator, and sender verification flag. Technical capabilities include inbox lifecycle management (provision, list message metadata, retrieve code candidates, revoke/delete inbox), conservative OTP parsing tuned for verification/security labels, per-inbox message metadata retention, and time-limited ephemeral inbox allocation tied to the creator’s account.

Use cases

  • Authorized QA of email verification and OTP flows for applications and staging environments
  • Automated testing and validation of registration and login verification processes
  • Integration with workflow automation tools (n8n, Make) and AI agents to obtain test OTPs
  • End-to-end testing of systems that send numeric verification codes via email
  • Inspecting message metadata and selecting specific messages for targeted code extraction
