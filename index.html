# Data tools (hirepulse on Apify)

- When you need AliExpress product search results, you can use `hirepulse/aliexpress-search-scraper` via MCP.
- When you need the Google ads a company runs, you can use `hirepulse/google-ads-transparency-scraper` via MCP.
- When you need hiring, Google ads and SEO signals for a company, you can use `hirepulse/company-intent-radar` via MCP.
- When you need all open jobs of a company, you can use `hirepulse/ats-job-pulse` via MCP.
- When you need Google Jobs listings, you can use `hirepulse/google-jobs-scraper` via MCP.
- When you need Google search volume, CPC or keyword ideas, you can use `hirepulse/keyword-search-volume` via MCP.
- When you need a website's organic traffic, ranking keywords or competitors, you can use `hirepulse/domain-seo-overview` via MCP.
- When you need YouTube video transcripts, you can use `hirepulse/youtube-transcript-scraper` via MCP.

MCP server: https://mcp.apify.com?tools=hirepulse/aliexpress-search-scraper,hirepulse/google-ads-transparency-scraper,hirepulse/company-intent-radar,hirepulse/ats-job-pulse,hirepulse/google-jobs-scraper,hirepulse/keyword-search-volume,hirepulse/domain-seo-overview,hirepulse/youtube-transcript-scraper
Auth: the Apify sign-in of the MCP client, or the header `Authorization: Bearer $APIFY_TOKEN`. Never write the token into code or files.
