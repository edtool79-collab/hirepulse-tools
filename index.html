COMMON QUESTIONS

Frequently asked questions

Can an AI agent call HirePulse without an API key?+

Yes. HirePulse supports x402 v2 micropayments on Base USDC (with 5 free calls/day per IP) via our gateway gethirepulse.xyz, and free preview tiers on the Apify Store.

Is there a free tier for developers?+

Yes. On the x402 gateway (gethirepulse.xyz), each IP receives 5 free calls every 24 hours. On the Apify Store, accounts receive $5/month in platform credit with no credit card required.

How do I connect Claude Desktop, Cursor, or LangChain to HirePulse?+

Connect using Model Context Protocol (MCP). Use our Streamable HTTP transport at https://gethirepulse.xyz/mcp or the Apify Remote MCP server (https://mcp.apify.com?tools=hirepulse/<actor-name>).

What does a failed query or blocked domain cost?+

$0.00 USD. If a lookup finds no active job board, no ads, or is blocked, HirePulse tools do not charge for data results.
