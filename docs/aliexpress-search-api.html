AliExpress search results as JSON (Python, n8n, API)

Get AliExpress search results as clean JSON: product title, price in your currency, original price, rating, sold count, store and product URL. 60 products per page, no browser.

Open AliExpress Search Scraper on Apify

What you get

  • Any search query, sorted results, 60 products per page
  • Choose ship-to country and currency
  • Price, original price, rating, orders sold, store, image and product link
  • Plain HTTP with automatic proxy fallback, so runs are fast and cheap

Pricing

$2.50 per 1,000 products (pay per result, no subscription). Free Apify plan: 100 products per run.

Call it with cURL

curl -X POST "https://api.apify.com/v2/acts/hirepulse~aliexpress-search-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["wireless earbuds"], "max_results_per_query": 120, "ship_to": "US", "currency": "USD"}'

Python

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("hirepulse/aliexpress-search-scraper").call(run_input={"queries": ["wireless earbuds"], "max_results_per_query": 120, "ship_to": "US", "currency": "USD"})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

Use with AI agents and n8n

AI agents can call it through Apify's MCP server: https://mcp.apify.com/?tools=hirepulse/aliexpress-search-scraper. In n8n, use the Apify node or an HTTP Request node with the cURL call above.
