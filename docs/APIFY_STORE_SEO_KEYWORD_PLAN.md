## 1. Apify Store Ranking Algorithm & Ranking Factors

Apify Store functions as a specialized commercial search engine. The ranking algorithm prioritizes:
1. **Actor Title (Exact & Broad Match):** Placement of high-intent search terms (e.g., "Clay alternative", "BuiltWith", "Greenhouse scraper") in the primary title.
2. **Tagline / Short Description:** High keyword density in the first 160 characters displayed on store cards.
3. **SEO Title & Meta Description:** Custom Google search metadata configured in the Apify Console.
4. **README Headings (H1, H2) & Task Names:** Structured semantic entities and keyword-rich task presets.
5. **Historical Run Success Rate:** HirePulse maintains a **100% success rate** across its original 12 actors—this high quality score gives HirePulse a decisive organic boost over failing community scrapers.

## 3. High-Converting Optimization for the 80 Published Tasks

Each of the 80 published tasks serves as a permanent, crawlable landing page on Google and Apify Store:

### 1. Keyword Injection Formula for Task Names
- **Pattern:** `[Action Verb] + [Brand / Tech Name] + [Core Keyword]`
- **Examples:**
  - `Scrape Datadog Greenhouse Engineering Roles` (Targeting: Datadog jobs, Greenhouse scraper)
  - `Inspect Stripe Frontend Stack & Cloudflare CDN` (Targeting: BuiltWith Stripe, tech stack lookup)
  - `Spy on Notion Google Ads Search Creatives` (Targeting: Notion ads, Google Ads spy)
  - `Find Linear Ashby Job Board URL` (Targeting: Linear careers, Ashby scraper)

### 2. Task Markdown Meta Descriptions
Ensure the task description begins with:
- The exact use case and ICP match.
- Explicit pricing / cost notice (`Native mode: $0.00 upstream spend`).
- Clear evidence limitations (e.g. "Public snapshot, not guaranteed total historical ad spend").

## 4. Web Console Step-by-Step Update Protocol (Zero-Push, Zero-Risk)

To update titles, taglines, and categories **WITHOUT** triggering builds or altering code:

1. Open a web browser and navigate to [https://console.apify.com/actors](https://console.apify.com/actors).
2. Select the Actor from the list (e.g. `hirepulse/website-tech-stack-detector`).
3. Click on the **Settings** tab in the top navigation bar.
4. Update the following fields directly:
   - **Title:** Paste the optimized title from the matrix above.
   - **Description / Tagline:** Paste the optimized 160-character tagline.
   - **SEO Title:** Use `[Optimized Title] | Apify Store`.
   - **SEO Description:** Paste the benefit-driven description emphasizing speed and cost savings.
   - **Categories:** Ensure relevant categories (e.g. `Developer tools`, `Lead generation`) are checked.
5. Click **Save changes** at the bottom of the page.
6. **DO NOT** click "Build", **DO NOT** edit source files in the web IDE, and **DO NOT** run `apify push` locally.
7. Verify that the public store listing reflects the updated metadata by opening `https://apify.com/hirepulse/<actor-name>` in an incognito window.
