Greenhouse, Lever and Ashby jobs API: every open job of a company

Every open job from a company's Greenhouse, Lever, Ashby, Workable, Recruitee or SmartRecruiters job board, by domain or board name, with location, department, remote flag, salary when published and apply link.

Open ATS Job Scraper on Apify

What you get

  • Give a domain like stripe.com, the job board is found automatically
  • Six ATS systems supported (not Workday)
  • Department, location, remote flag, posting date and apply URL
  • Only-new-jobs tracking between runs

Pricing

Pay per result on the Apify Store, see the tool page for current prices.

Call it with cURL

curl -X POST "https://api.apify.com/v2/acts/hirepulse~ats-job-pulse/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"companies": ["stripe.com", "notion.so"]}'

Python

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("hirepulse/ats-job-pulse").call(run_input={"companies": ["stripe.com", "notion.so"]})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

Use with AI agents and n8n

AI agents can call it through Apify's MCP server: https://mcp.apify.com/?tools=hirepulse/ats-job-pulse. In n8n, use the Apify node or an HTTP Request node with the cURL call above.
