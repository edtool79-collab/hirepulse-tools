How to scrape AliExpress search results with Python

Get AliExpress search results as JSON with Python: titles, prices in your currency, ratings, orders sold and links. No browser, 60 products per page.

Scraping e-commerce marketplaces like AliExpress is notoriously challenging. Traditional scraping setups rely on headless Chromium instances running Puppeteer or Playwright, paired with expensive residential proxy networks to avoid bot detection and rate limits. These browser setups are slow, resource-heavy, and prone to breaking when marketplace layouts shift.

The AliExpress Search Scraper eliminates browser overhead entirely. It interacts directly with AliExpress’s backend data endpoints over plain HTTP with automatic proxy fallback. The result is fast, reliable product data extraction returning 60 products per page in clean JSON format.

Whether you are performing competitor price benchmarking, dropshipping product research, or e-commerce catalog audits, this guide shows you how to query AliExpress search results programmatically using Python and cURL.

Data attributes extracted per product

For each matching product listing, the scraper extracts clean commercial and catalog attributes:

  • Identification & links: The full title, canonical product_url, and primary product image.
  • Pricing & discounts: The active selling price and strikethrough original_price, denominated in your selected currency.
  • Social proof & traction: The average customer rating (0 to 5 stars) and total orders_sold volume.
  • Merchant information: The selling store name.
  • Localization: Accurate pricing and shipping estimates based on your chosen ship_to country and currency.

Quick start with cURL

You can execute a search run immediately with a single HTTP POST request. Replace YOUR_APIFY_TOKEN with your personal token:

curl --fail-with-body -X POST "https://api.apify.com/v2/acts/hirepulse~aliexpress-search-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "queries": [
    "wireless earbuds"
  ],
  "max_results_per_query": 120,
  "ship_to": "US",
  "currency": "USD"
}'

This request queries the term "wireless earbuds" localized for shipping to the United States (US) with pricing formatted in US Dollars (USD), capping results at 120 products (2 pages of 60 items each).

Building a Python product research pipeline

Using the official apify-client package, you can run search queries, compute product discounts, sort items by sales velocity, and save the dataset to a structured file.

pip install apify-client
import os
import json
from pathlib import Path
from apify_client import ApifyClient

# Initialize the Apify client
client = ApifyClient(os.environ.get("APIFY_TOKEN", "YOUR_APIFY_TOKEN"))

# Define search parameters
run_input = {
    "queries": ["wireless earbuds"],
    "max_results_per_query": 120,
    "ship_to": "US",
    "currency": "USD"
}

# Run the Actor and wait for dataset completion
run = client.actor("hirepulse/aliexpress-search-scraper").call(run_input=run_input)

if not run or run.get("status") != "SUCCEEDED":
    raise RuntimeError(f"Actor failed with status: {run.get('status')}")

# Iterate over returned dataset items
raw_products = list(client.dataset(run["defaultDatasetId"]).iterate_items())
print(f"Retrieved {len(raw_products)} products from AliExpress.\n")

# Process and analyze product records
catalog = []
for p in raw_products:
    title = p.get("title", "Untitled Product")
    price = p.get("price")
    orig_price = p.get("original_price")
    rating = p.get("rating")
    sold_count = p.get("orders_sold", 0)
    store = p.get("store", "Unknown Merchant")
    link = p.get("product_url", "")

    # Calculate discount percentage if original price is available
    discount_pct = 0
    if price and orig_price and orig_price > price:
        discount_pct = round(((orig_price - price) / orig_price) * 100, 1)

    catalog.append({
        "title": title,
        "price": price,
        "original_price": orig_price,
        "discount_pct": discount_pct,
        "rating": rating,
        "orders_sold": sold_count,
        "store": store,
        "product_url": link
    })

# Sort catalog by total sales volume (descending)
sorted_catalog = sorted(catalog, key=lambda x: x["orders_sold"], reverse=True)

# Display top 5 best-selling items
print("--- Top 5 Best-Selling Listings ---")
for item in sorted_catalog[:5]:
    print(f"[{item['orders_sold']:,} sold | {item['rating']}★] {item['title'][:60]}...")
    print(f"  Price: ${item['price']} (Orig: ${item['original_price']}, -{item['discount_pct']}%) | Store: {item['store']}\n")

# Save processed results to JSON
Path("aliexpress_results.json").write_text(
    json.dumps(sorted_catalog, indent=2, ensure_ascii=False),
    encoding="utf-8"
)

Practical tips for e-commerce data engineering

1. Consistent localization settings

Product availability, shipping fees, and local pricing vary significantly across geographies. When comparing runs or building historical pricing models, ensure that ship_to and currency remain fixed across your queries. Mixing currencies or shipping destinations without normalizing records will skew discount and margin calculations.

2. Handling missing or zero sales counts

Newer product listings or seasonal variations may show orders_sold: 0 or omit original pricing if the merchant never ran a promotional strikethrough price. Always use Python’s .get() method to handle missing fields without raising runtime errors.

3. Rate limiting and pagination

The tool extracts 60 products per page. Setting max_results_per_query: 120 fetches two pages. For large catalog audits across dozens of queries, keep your batches modular (e.g., 5 to 10 queries per run) so your downstream processing can validate datasets incrementally.

Limitations and pricing

  • Catalog scope: This tool is an optimized search results scraper. It captures all public catalog card attributes (title, price, ratings, sold count, store, and URL). It does not scrape individual customer review paragraphs, seller private messaging, or checkout coupon codes.
