How this was made

Every number comes from the company’s own public job board API, fetched at the time above. “New/updated” uses the posting date each board publishes (some boards report the last update instead of the first publish date). Companies on Workday or custom career sites are not included.

The data was collected with the same code as the ATS Job Scraper (every open job from a company’s Greenhouse, Lever, Ashby, Workable, Recruitee or SmartRecruiters board) and the Company Intent Radar (hiring + Google ads + SEO signals per domain), both on the Apify Store. You can run the same lookup for your own list of companies.

The report also lives at https://edtool79-collab.github.io/hirepulse-tools/hiring-report.html and is updated every week.
