HIREPULSE / DATA API

Google Ads Transparency Center API: every ad a company runs, by domain

Pass a company domain and get its Google ads from the Ads Transparency Center: preview image, format, first and last shown dates, advertiser and verification. Bulk domains, summary mode and 'only new ads' monitoring.

Open in Apify Store ↗

THE OUTPUT

What you get

  • ✓Domains in, ads out: no advertiser IDs or Google URLs needed
  • ✓Text, image and video ads with preview image and Transparency Center link
  • ✓Summary mode: one row per domain (does it advertise, how many ads, formats, latest ad)
  • ✓'Only new ads' mode for scheduled competitor monitoring
  • ✓Shows every advertiser whose ads lead to the domain, useful for brand protection

MAKE YOUR FIRST CALL

A little code. Useful data.

Replace YOUR_APIFY_TOKEN with your Apify token. For Python, install the apify-client package in your own environment.

cURL POST / run-sync-get-dataset-items
curl -X POST "https://api.apify.com/v2/acts/hirepulse~google-ads-transparency-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "domains": [
    "nike.com"
  ],
  "country": "US",
  "max_ads_per_domain": 40,
  "mode": "ads"
}'
Python apify_client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("hirepulse/google-ads-transparency-scraper").call(
    run_input={
      "domains": [
        "nike.com"
      ],
      "country": "US",
      "max_ads_per_domain": 40,
      "mode": "ads"
    }
)

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
